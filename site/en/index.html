Sentinelle, the open source EDR in Rust: Seven alerts.
One incident.

Sentinelle rebuilds process ancestry, applies 51 Sigma-style rules and folds a sequence's alerts into one incident. Written in Rust, self-hosted, for Windows, Linux and macOS. And it shows you what it doesn't cover yet.

Under the hood

How an EDR in Rust works: from sensor to console

From the kernel to the analyst's screen, everything runs on your machines: no telemetry is sent to a vendor.

  1. 01

    Windows, Linux, macOS: one sensor per system

    Windows: kernel ETW (administrator rights), with automatic fallback to polling. Linux and macOS: process-table polling, roughly once per second; it can miss very short-lived processes.

    ETW · pushed by the kernel

    polling · ~1 s

    illustration
    › process_start · powershell.exe · pid 4200

  2. 02

    Who launched whom

    A flat ECS/OCSF-style schema for 8 event types, plus the full ancestry of every process: a rule can require an Office ancestor.

    explorer.exewinword.exe Office ancestor ✓powershell.exe
    › powershell.exe ← winword.exe ← explorer.exe

  3. 03

    Readable Sigma-style rules

    Operators equals, contains, starts_with, ends_with, regex, cidr; an and/or/not tree; lineage. Sigma YAML import: base64, windash, cidr, all, “1 of” and “all of”.

    {
  "id": "SNT-0010",
  "title": "PowerShell avec commande encodee",
  "severity": "high",
  "attack": ["T1059.001", "T1027"],
  "kind": "process_start",
  "all": [
    { "field": "ImageName", "op": "equals",
      "values": ["powershell.exe", "pwsh.exe"] },
    { "field": "CommandLine", "op": "contains",
      "values": ["-encodedcommand", "-enc ", " -e "] }
  ]
}
    title: PowerShell avec chaîne encodée en base64
id: snt-sigma-ps-b64
level: high
tags: [attack.t1059.001, attack.t1027]
logsource: { category: process_creation, product: windows }
detection:
  selection:
    Image|endswith: '\powershell.exe'
    CommandLine|base64|contains:
      - 'Net.WebClient'
      - 'DownloadString'
      - 'IEX'
  condition: selection
    › SNT-0010: ImageName equals ✓ · CommandLine contains "-enc " ✓

  4. 04

    What a single rule can't see

    Four stateful detectors, plus a YARA-X scan of process images.

    • B001 process-creation burst
    • B002 mass file encryption sim (simulation-only)
    • B003 parent spoofing sim (simulation-only)
    • B004 renamed sensitive binary

    svchost.exe → PowerShell.EXE

    › replay: SNT-B003 · SNT-B004

  5. 05

    From alerts to an incident

    Per-host risk that builds up and decays, weighted by each rule's confidence; allowlist and deduplication. Same host, 120 s: one incident.

    • critical 100
    • high 70
    • medium 40
    • low 15
    • info 5
    › 100 + 70 + 40 = 210

  6. 06

    Real-time SOC console, remote kill

    An SSE console built into the binary. Win32 process termination, local or remote. Exports: Markdown report, ATT&CK Navigator layer, incidents as JSON.

    illustration
    › /api/respond/kill/{host}/{pid}

  7. 07

    Self-hosted: one endpoint or a whole fleet over gRPC + mTLS

    Agents and a central server over mutual TLS (tonic + rustls), a pure-Rust PKI (rcgen), kill orders pushed to agents, a liveness heartbeat.

Blind spots

Real coverage: what Sentinelle can't see yet

A blind spot you show is a blind spot you can fix. Its API reports it itself: GET /api/coverage/reality.

45/ 51

rules fed by a live sensor

live simulation-only

Not a replacement for CrowdStrike, SentinelOne or Microsoft Defender for Endpoint. To learn, audit, self-host or complement: yes.

45 of the 51 rules rely on a live sensor. The other 6 exist but still wait for their sensor source (Sysmon, additional ETW providers):

  • SNT-0100 network
  • SNT-0101 file write
  • SNT-0200 image or driver load
  • SNT-0300 LSASS handle access
  • SNT-0310 remote thread
  • SNT-0320 named pipe

Add the SNT-B002 (file writes) and SNT-B003 (real parent) detectors, which have no live source either; the endpoint only lists rules.

curl http://localhost:8787/api/coverage/reality

Validated on real hardware

  • Windows 11 Pro: live kernel ETW, SNT-0012, SNT-B001 and SNT-B004 detections on real processes
  • Real Win32 kill, live mTLS fleet, SQLite that survives a restart, Sigma import, YARA
  • macOS: real sensor, real SNT-1002 detection; one false positive found, then fixed
  • Ubuntu + Windows CI on every commit (fmt + clippy -D warnings), 63 tests
  • Benign Windows and Linux corpus: 0 false positives on this corpus

What it isn't (yet)

  • No kernel anti-tamper (PPL / MVI): an administrator can stop the agent
  • No large-scale threat intelligence, no 24/7 SOC
  • Unsigned binaries: Defender may quarantine them
  • Outside Windows, polling can miss very short-lived processes
  • Alpha, a single maintainer

Roadmap: wire the sensor sources for the 6 rules and for SNT-B002 / SNT-B003. Contribute on GitHub ↗

Get started

Install the self-hosted EDR in three commands

Prerequisite: the Rust toolchain (cargo). Then open the console at http://localhost:8787 (fleet: the server's, at http://localhost:8080).

Single endpoint

git clone https://github.com/Pazificateur69/sentinelle-edr
cd sentinelle-edr
cargo run --release -p sentinelle-agentd

Replay the demo

SENTINELLE_REPLAY_FILE=./captures/demo.jsonl cargo run --release -p sentinelle-agentd

mTLS fleet

cargo run -p sentinelle-certgen -- ./certs
cargo run --release -p sentinelle-server
SENTINELLE_HOST=poste-1 cargo run --release -p sentinelle-agent

Set SENTINELLE_TOKEN before exposing the server: without a token, its kill response route is open. The single-host agent listens on 127.0.0.1 and leaves kill and simulate open until a token is set.

Windows: run the terminal as Administrator for ETW. Defender may quarantine these unsigned binaries: exclude the folder in Windows Security.

FAQ

Sentinelle EDR: frequently asked questions

Another question? Open an issue ↗

What is an open source EDR?

An EDR (Endpoint Detection & Response) monitors activity on endpoints (processes and more), detects malicious behavior and lets you respond to it. Sentinelle is open source under the MIT license: its code and its 51 rules are readable and auditable.

How does an EDR work?

A sensor observes endpoint activity; for Sentinelle in live mode, that means process creations. Each event is normalized, attached to the process tree, evaluated by rules and behavioral detectors, scored, then correlated with the host's other alerts into incidents, which an analyst reviews and can act on, for example by killing a process.

Does Sentinelle replace CrowdStrike, SentinelOne or Microsoft Defender for Endpoint?

No. Sentinelle has no kernel anti-tamper, no large-scale threat intelligence and no 24/7 SOC. It is meant for learning, auditing, self-hosting or complementing an existing setup.

Is Sentinelle self-hosted? Does it send data to a vendor?

Yes, it is fully self-hosted: no telemetry is sent to any vendor.

Which operating systems are supported?

Windows (ETW sensor, with polling as a fallback), Linux and macOS (process-table polling, roughly every second). 39 Windows rules and 12 Linux/macOS rules.

Is it compatible with Sigma rules?

Yes: it imports Sigma YAML rules with the base64, windash, cidr and all modifiers, and the “1 of” and “all of” quantifiers.

How is MITRE ATT&CK coverage measured?

Each rule declares its ATT&CK techniques: 51 distinct techniques and sub-techniques (37 base techniques), 10 tactics covered. Initial Access is not covered. The console exports an ATT&CK Navigator layer (/api/navigator).

What does “simulation-only” mean?

6 rules (network, file write, image load, LSASS handle access, remote thread, named pipe) exist but don't have a live sensor yet. They fire during replay. The /api/coverage/reality endpoint reports this. The SNT-B002 (file writes) and SNT-B003 (real parent) behavioral detectors have no live source either; that endpoint does not mention them.

Why does Windows Defender quarantine Sentinelle?

The binaries are not signed (Authenticode). That is expected for an unsigned EDR: exclude the folder in Windows Security.

Does it need administrator rights?

On Windows, yes, for the ETW sensor. Without them, Sentinelle automatically falls back to polling.

Can I use it in production?

Sentinelle is alpha software maintained by a single person. Read the known limitations before any deployment.

How do I add a rule?

Add a JSON entry to crates/common/rules.json and rebuild (native rules are compiled into the binary), or drop a Sigma YAML file into a folder set via SENTINELLE_RULES_DIR (for example ./rules.d). An allowlist helps reduce false positives.
