Sous le capot

Comment fonctionne un EDR en Rust : du capteur à la console

Du noyau jusqu'à l'écran de l'analyste, tout tourne chez vous : aucune télémétrie n'est envoyée à un éditeur.

  1. 01

    Windows, Linux, macOS : un capteur par système

    Windows : ETW noyau (droits administrateur), repli automatique sur la scrutation. Linux et macOS : scrutation de la table des processus, environ chaque seconde ; elle peut rater les processus très brefs.

    ETW · poussé par le noyau

    scrutation · ~1 s

    illustration

  2. 02

    Qui a lancé qui

    Un schéma plat façon ECS/OCSF pour 8 types d'événements, et l'ascendance complète de chaque processus : une règle peut exiger qu'un ancêtre soit Office.

    explorer.exewinword.exe ancêtre Office ✓powershell.exe

  3. 03

    Des règles façon Sigma, lisibles

    Opérateurs equals, contains, starts_with, ends_with, regex, cidr ; arbre and/or/not ; lignée. Import de règles Sigma YAML : base64, windash, cidr, all, « 1 of » et « all of ».

Démarrer

Installer l'EDR auto-hébergé en trois commandes

Prérequis : la chaîne d'outils Rust (cargo). Puis la console sur http://localhost:8787 (en parc : celle du serveur, http://localhost:8080).

sentinelle — zsh

Mono-poste

git clone https://github.com/Pazificateur69/sentinelle-edr
cd sentinelle-edr
cargo run --release -p sentinelle-agentd

Rejouer la démo

SENTINELLE_REPLAY_FILE=./captures/demo.jsonl cargo run --release -p sentinelle-agentd

Parc mTLS

cargo run -p sentinelle-certgen -- ./certs
cargo run --release -p sentinelle-server
SENTINELLE_HOST=poste-1 cargo run --release -p sentinelle-agent

Définissez SENTINELLE_TOKEN avant d'exposer le serveur : sans jeton, sa route de réponse kill est ouverte. L'agent mono-poste, lui, écoute sur 127.0.0.1 et laisse kill et simulate ouvertes tant qu'aucun jeton n'est défini.

Windows : lancez le terminal en Administrateur pour l'ETW. Defender peut mettre ces binaires non signés en quarantaine : excluez le dossier via Sécurité Windows.

FAQ

Questions fréquentes sur Sentinelle EDR

Une autre question ? Ouvrez une issue ↗

Qu'est-ce qu'un EDR open source ?

Un EDR (Endpoint Detection & Response) surveille l'activité des postes (processus, etc.), détecte les comportements malveillants et permet d'y répondre. Sentinelle est open source sous licence MIT : son code et ses 51 règles sont lisibles et auditables.

Comment fonctionne un EDR ?

Un capteur observe l'activité du poste ; pour Sentinelle en live, ce sont les créations de processus. Chaque événement est normalisé, rattaché à l'arbre de processus, évalué par des règles et des détecteurs comportementaux, noté, puis corrélé avec les autres alertes du même hôte en incidents, qu'un analyste consulte et sur lesquels il peut agir, par exemple en terminant un processus.

Sentinelle remplace-t-il CrowdStrike, SentinelOne ou Microsoft Defender for Endpoint ?

Non. Sentinelle n'a ni anti-tamper noyau, ni renseignement sur la menace à grande échelle, ni SOC 24/7. Il sert à apprendre, auditer, auto-héberger ou compléter.

Sentinelle est-il auto-hébergé ? Envoie-t-il des données à un éditeur ?

Oui, il est entièrement auto-hébergé : aucune télémétrie n'est envoyée à un éditeur.

Quels systèmes sont pris en charge ?

Windows (capteur ETW, repli sur la scrutation), Linux et macOS (scrutation de la table des processus, environ 1 s). 39 règles Windows et 12 règles Linux/macOS.

Est-il compatible avec les règles Sigma ?

Oui : import de règles Sigma YAML avec les modificateurs base64, windash, cidr et all, et les quantificateurs « 1 of » et « all of ».

Comment la couverture MITRE ATT&CK est-elle mesurée ?

Chaque règle déclare ses techniques ATT&CK : 51 techniques et sous-techniques distinctes (37 techniques de base), 10 tactiques couvertes. Initial Access n'est pas couvert. La console exporte une couche ATT&CK Navigator (/api/navigator).

Que signifie « simulation-seulement » ?

6 règles (réseau, écriture fichier, chargement d'image, accès handle LSASS, thread distant, tube nommé) existent mais n'ont pas encore de capteur live. Elles se déclenchent en rejeu. L'endpoint /api/coverage/reality l'indique. Les détecteurs comportementaux SNT-B002 (écritures de fichiers) et SNT-B003 (parent réel) n'ont pas non plus de source live ; cet endpoint ne les mentionne pas.

Pourquoi Windows Defender met-il Sentinelle en quarantaine ?

Les binaires ne sont pas signés (Authenticode). C'est normal pour un EDR non signé : excluez le dossier via Sécurité Windows.

Faut-il les droits administrateur ?

Sous Windows, oui pour le capteur ETW. Sans eux, Sentinelle bascule automatiquement sur la scrutation.

Peut-on l'utiliser en production ?

Sentinelle est en statut alpha et maintenu par une seule personne. Lisez les limites avant tout déploiement.

Comment ajouter une règle ?

Ajoutez une entrée JSON dans crates/common/rules.json, puis recompilez (les règles natives sont intégrées au binaire), ou déposez un fichier Sigma YAML dans un dossier désigné par SENTINELLE_RULES_DIR (par exemple ./rules.d). Une allowlist permet de réduire les faux positifs.
